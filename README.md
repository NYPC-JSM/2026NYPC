# 2026 NYPC MASTER TRACK — 대전 전략 AI

2026 NYPC(NEXON Young Programmers Challenge) MASTER TRACK에  
2인 팀으로 참가해 개발한 대전 전략 AI입니다.

200턴 동안 경제·병력·거점·전투를 함께 운영하며 상대 본부를 파괴하는 게임으로,  
**1,603팀 중 104위(상위 약 6%)**를 기록했습니다.

- 기간: 2026.06.29 ~ 2026.07.08
- 인원: 2명
- 언어: C++17

---

## 개발 과정

### 규칙 기반 전략의 한계

초기에는 경제 운영, 거점 확장, 방어, 공격 조건을 직접 정의하는 규칙 기반 방식으로 개발했습니다.

샘플봇을 상대로는 성능이 좋아졌지만, 조건을 세밀하게 조정할수록 실제 래더에서는 성적이 오히려 떨어지는 경우가 발생했습니다. 이를 특정 상대와 상황에 전략이 맞춰지는 과적합 문제로 판단했습니다.

### 독립된 두 봇으로 실험

하나의 전략만 계속 수정하는 대신, 팀원 각자가 독립된 코드베이스에서 서로 다른 방향의 전략을 개발했습니다.

두 봇을 서로 대전시키며 약점을 찾고, 한쪽에서 발견한 문제를 다른 전략의 개선에도 활용하는 방식으로 테스트 범위를 넓혔습니다.

### 시뮬레이션 기반 의사결정

최종적으로는 현재 게임 상태에서 여러 전략 후보를 생성하고, 각 후보의 미래 상태를 시뮬레이션한 뒤 결과를 평가하는 Rollout 기반 구조를 적용했습니다.

주요 전략 후보는 다음과 같습니다.

- `ECON` — 경제 성장
- `TECH` — 본부 및 거점 강화
- `RAID` — 상대 거점 공격
- `ASSAULT` — 상대 본부 공격
- `DEFEND` — 방어
- `FINISH` — 후반 승부 결정

경제력, 병력, 건물, 본부 HP 등을 종합적으로 평가하고 가장 높은 결과를 얻은 전략의 첫 행동을 실제 명령으로 사용합니다.

## 래더 분석

승패만 확인하지 않고 실제 경기 로그를 분석하기 위한 Python 스크립트를 별도로 작성해 사용했습니다.

병력 생산량, 거점 확보, 공격 시점, 건물 피해, 병력 집결·후퇴 패턴 등을 분석하며

**전략 수정 → 자체 대전 → 래더 제출 → 로그 분석 → 재수정**

과정을 반복했습니다.
